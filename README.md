# Darkula Activate

A Discord bot built with Node.js and Discord.js.

## Features

- /darkula activate
- Create text channels
- Custom channel names
- Configurable channel quantity
- Custom messages
- Configurable message count
- Rate-limit-aware API requests

## Setup

1. Install Node.js.
2. Run npm install.
3. Create a .env file.
4. Add your Discord bot token,
   application ID and server ID.
5. Run npm start.

## Security

Never share your bot token.
